# Getting Started with Krewire Community Portal

This guide explains how to develop, preview, and build the **`krewire.github.io`** community portal locally.

---

## Prerequisites

1. **`kiw` CLI**: Built from the `krewire` repository:
   ```bash
   cd /home/reasvyn/workspace/krewire/krewire
   go build -o ../bin/kiw ./tools/kiw/cmd/kiw
   ```
2. **Git**: Configured for interacting with the repository.
3. **No Local Go Dependencies**: As a static site project, `krewire.github.io` runs directly via the `kiw` devtool without needing a `go.mod` file.

---

## Local Development Workflow

### 1. Build Static Artifacts

Compile the portal into `.krewire/build/`:

```bash
cd /home/reasvyn/workspace/krewire/krewire.github.io
kiw build
```

This command parses the `.kiw` files in `pages/`, applies the layouts in `layouts/`, bundles static assets from `public/`, and produces ready-to-deploy static files.

### 2. Live Preview

Run the development server to test changes with live reload:

```bash
kiw serve
```

Open `http://localhost:8080` in your web browser.

## Working with Portal Content

### Page Structure & Routing

- `pages/index.kiw`: The main single-page community portal containing sections for:
  - Hero and ecosystem statistics.
  - Contributor privileges & meritocracy tiers.
  - 8-repository codebase matrix.
  - Contributor 3 quality gates.
  - Transparent sponsorship tiers.
  - AI Boost workflow intro.

### Localization & Bilingual Parity

- Content is localized across English (`en`) and Indonesian (`id`).
- Dictionaries are stored in `lang/en/` and `lang/id/`.
- Ensure new sections or strings are mirrored across both languages to maintain full parity.

### Theme & Design Tokens

Theme colors are defined in `krewire.yaml` under `theme:`:
- Light theme: Crisp paper base (`#FAF8F4`) with primary emerald (`#39D353`) and brand navy (`#0B1F3B`).
- Dark theme: Dark navy base (`#0B1F3B`) with emerald accents.
- Scoped component styles use `data-kiw-*` attributes automatically generated by `kiw build`.
