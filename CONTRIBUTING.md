# Contributing to krewire.github.io

Guidelines for contributing to the **Krewire Community Portal** (`github.com/krewire/krewire.github.io`).

> All code, comments, docstrings, commit messages, and documentation are strictly in **English**.

## Invariants

1. **Bilingual Support**: Maintain both English and Indonesian strings in community resources.
2. **Build Verification**: Every modification must build cleanly via `krew build`.
